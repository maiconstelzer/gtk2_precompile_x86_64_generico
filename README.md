### Dicas
---
- Acaso deseje utilizar no seu sitemas linux, mover os arquivos conforme a estrutura deste repositório em seu respectivo sistema, e.g arquivos da pasta 'etc' vão para pasta '/etc' do seu sistema e assim sucessivamente;
- Acaso deseje utilizar pontualmente (e.g rodar um launcher de jogo), criar uma nova pasta no local do launcher (e.g gtk2), mover as pastas 'etc' e 'usr' para pasta e executar o launcher utilizando a variável de ambiente 'LD_LIBRARY_PATH' (e.g LD_LIBRARY_PATH=./gtk2/usr/lib/ ./WurmLauncher);
